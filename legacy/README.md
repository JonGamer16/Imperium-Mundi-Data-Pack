# legacy/

Not loaded by Minecraft: `legacy/` has no `pack.mcmeta`, so the game ignores everything under it.

- `mundi-2026/`: the original Imperium Mundi data pack (this repo's `main` before 10/31/26, last
  commit `73fd4c0`). Older kits, enchantments, game modes (team deathmatch, kit PvP events), the
  Player DB, and vanilla recipe overrides. Kept to pick pieces from; port anything you reuse into
  one of the three packs and update it for 26.3 (see `../../CLAUDE.md`).
